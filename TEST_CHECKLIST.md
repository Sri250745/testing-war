# Manual check for the first slice

- [ ] GitHub Actions workflow finishes successfully and uploads `testing-war-jar`.
- [ ] Install the compiled mod and matching Fabric API into a separate 26.3 Fabric instance.
- [ ] Create a new creative test world.
- [ ] Run `/summon testing_war:citizen`.
- [ ] Confirm a player-shaped humanoid with a visible `Citizen-...` name appears.
- [ ] Wait briefly and confirm it wanders.
- [ ] Save and quit, reopen the same test world, and confirm the entity and visible name remain.

Not covered by this check: NPC inventories, gathering, crafting, hunger, combat, kingdoms, interdimensional progression, or voice.
